# 0. Avant de commencer

[← Accueil](../README.md) · Suivant : [Installer l'application →](01-installer.md)

## Qui peut participer

- 18 ans ou plus.
- Un compte actif sur au moins un site : **Moodle UQAM**, **Mon Portail**, ou un autre site que
  vous utilisez (intranet, portail d'organisation, site documentaire).
- Vous comprenez le français, l'anglais ou l'espagnol.
- Vous n'avez jamais utilisé PT2026 et vous ne faites pas partie de l'équipe de développement.

| Profil | Sites que vous connecterez pendant la séance |
|---|---|
| **A — Étudiant(e)** | Moodle UQAM **et** Mon Portail, dans le même espace |
| **B — Professeur(e) / chargé(e) de cours** | Moodle UQAM (et éventuellement un site institutionnel) |
| **C — Employé(e) / professionnel(le)** | Un « Autre site » (intranet, portail, site documentaire) |

## Ce qu'il vous faut

| Élément | Exigence |
|---|---|
| Système | Windows 10/11 64 bits, macOS 11 ou plus, ou Linux (Ubuntu 22.04 ou équivalent) |
| Mémoire | 8 Go au minimum, 16 Go recommandés |
| Disque | Environ 12 Go libres |
| Carte graphique | Facultative (les réponses sont plus rapides avec une carte de 6 Go ou plus) |
| Réseau | Wi-Fi fiable pour l'installation et la synchronisation |
| Alimentation | Pendant la séance, **branchez l'ordinateur portable sur secteur** (sur batterie, le modèle est beaucoup plus lent) |

Pas de carte graphique ou seulement 8 Go de mémoire ? Vous pouvez participer : les réponses
seront plus lentes, et c'est justement une des choses que nous mesurons. Si votre ordinateur a
moins de 8 Go, prévenez-nous : la séance se fera sur un poste de laboratoire.

## Ce qui reste sur votre ordinateur

| Donnée | Où |
|---|---|
| Pages et documents téléchargés de vos sites, index de recherche | Dossier de données de l'application (voir [Après le test](06-apres-le-test.md#où-sont-vos-données)) |
| Vos discussions | Même dossier |
| Mots de passe et sessions de connexion | Chiffrés dans le coffre du système (Windows, macOS, Linux) |
| Le modèle d'IA (Ollama) | Sur votre ordinateur ; il répond sans Internet |

L'application **ne collecte aucune statistique d'utilisation** et n'envoie rien à l'équipe. Les
seules connexions réseau sont celles vers les sites que **vous** connectez (Moodle, Mon Portail,
Microsoft pour la connexion).

Pendant l'étude, n'utilisez **pas** les fournisseurs en ligne (Gemini, OpenAI, Anthropic) que
l'application propose dans les réglages : l'étude porte uniquement sur le mode local.
